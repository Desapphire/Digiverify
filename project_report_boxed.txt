├──────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│ 1. INTRODUCTION                                                              │
│ ──────────────────────────────────────────────────────────────────────────── │
│ Digiverify (Squrify) is a modern, blockchain-based land registry and digital │
│ verification platform. It solves property fraud, lack of transparency, and   │
│ cumbersome manual processes in real estate. By leveraging Ethereum smart     │
│ contracts and IPFS, it ensures immutable and verifiable records.             │
│                                                                              │
│ 2. TECHNOLOGY STACK                                                          │
│ ──────────────────────────────────────────────────────────────────────────── │
│ [Backend]                                                                    │
│ - Node.js & Express: API framework.                                          │
│ - PostgreSQL: Relational database for structured data.                       │
│ - Ethers.js: Library for Ethereum smart contract interaction.                │
│ - Multer & IPFS: Secure document processing and decentralized storage.       │
│                                                                              │
│ [Frontend]                                                                   │
│ - React.js: Responsive UI library.                                           │
│ - Axios: HTTP client for API communication.                                  │
│ - Web3 Integration: Direct wallet interactions (MetaMask).                   │
│                                                                              │
│ [Blockchain]                                                                 │
│ - Solidity: Smart contract language.                                         │
│ - ERC-721 (NFTs): Property ownership representation.                         │
│                                                                              │
│ 3. SYSTEM ARCHITECTURE & ROLES                                               │
│ ──────────────────────────────────────────────────────────────────────────── │
│ - User: Register properties, initiate sales, manage portfolio.               │
│ - Authority: Verify documents and approve ownership transfers.               │
│ - Bank Admin: Manage fund blocking (ASBA-style).                             │
│ - Court: Legal oversight, freeze properties, reverse transactions.           │
│ - Super Admin: System configuration and monitoring.                          │
│                                                                              │
│ 4. CORE BUSINESS WORKFLOWS                                                   │
│ ──────────────────────────────────────────────────────────────────────────── │
│ [Property Registration]                                                      │
│ Details uploaded -> Files hashed to IPFS -> Authority Verifies -> NFT Minted │
│                                                                              │
│ [Secure Sale Workflow (Multi-Sig)]                                           │
│ 1. Initiation: Seller creates offer.                                         │
│ 2. Buyer Signature: Buyer accepts and signs.                                 │
│ 3. Fund Blocking: Bank places hold on buyer funds.                           │
│ 4. Authority Approval: Registry grants seal of approval.                     │
│ 5. Execution: Smart contract transfers NFT automatically.                    │
│                                                                              │
│ 5. TECHNICAL SPECIFICATIONS                                                  │
│ ──────────────────────────────────────────────────────────────────────────── │
│ [Key API Endpoints]                                                          │
│ - Auth: POST /api/auth/login                                                 │
│ - Property: POST /api/properties | POST /api/properties/:id/documents          │
│ - Sales: POST /api/sales/initiate | POST /api/sales/:id/complete             │
│ - Bank: POST /api/bank/block-funds                                           │
│ - Court: POST /api/court/freeze-property                                     │
│                                                                              │
│ [Primary Database Tables]                                                    │
│ - users, properties, sale_transactions, fund_blocks, audit_logs.             │
│                                                                              │
│ [Smart Contract Functions]                                                   │
│ - registerLand(), initiateSale(), confirmFunds(), executeTransfer().         │
│                                                                              │
│ 6. SECURITY FEATURES                                                         │
│ ──────────────────────────────────────────────────────────────────────────── │
│ - Blockchain Immutability: Permanent history.                                │
│ - IPFS Document Security: Tamper-proof storage.                              │
│ - KYC & Face Verification: Identity security.                                │
│ - Audit Trails: Append-only event logging.                                   │
│ - Wallet Recovery: Authority-guided NFT force-transfer.                      │
│                                                                              │
│ 7. CONCLUSION                                                                │
│ ──────────────────────────────────────────────────────────────────────────── │
│ Digiverify creates a trustless environment for real estate transactions,     │
│ combining web performance with blockchain security. It is a future-ready     │
│ solution for digital governance and asset management.                        │
